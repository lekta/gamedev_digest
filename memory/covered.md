- DirectX Shader Compiler официально поддержан на DX12 в Unity 6.6 (02.10): пост dnach, графическая команда Unity — «Unity 6.6 introduces official support for the DirectX Shader Compiler on DX12»; выбор бэкенда вынесен в список Shader Compiler Backend Selection в Shader Build Settings (File → Build Profiles → Graphics Settings), раньше только пер-шейдерная прагма под shader model 6; `#pragma require native16bit` переводит все `half` в `float16_t` (меньше регистров, экономия в storage-буферах), `#pragma require wavebasic` даёт обмен данными внутри wave без group shared memory; ограничения — «Compatibility with DXC is currently limited to the Windows build target using the DirectX12 graphics API», «DXC is not compatible with DX11», часть шейдеров на синтаксисе DX9–DX11 не собирается. [Unity Discussions](https://discussions.unity.com/t/directx-shader-compiler-support-for-dx12/1738167)
- Скомпилированный regex расходится с интерпретатором на атомарных группах (02.10): issue dotnet/runtime #135108 от pawlos, открыта, метки area-System.Text.RegularExpressions и untriaged — при жадном цикле внутри атомарной группы и последующей проверке границы слова `RegexOptions.Compiled` и генератор regex отвечают иначе, чем интерпретатор: с `\B` совпадение теряется, с `\b` находится ложное; `(?>.*\B)b` на «ab» — «ab» у интерпретатора против промаха у скомпилированного, `(?>.*\b)b` на «a b» — наоборот; воспроизводится на .NET 10 и 11 RC 1, на .NET 8 и 9 верно; обход — снять `Compiled` или заменить на обычную группу `(?:.*\B)b`. [GitHub](https://github.com/dotnet/runtime/issues/135108)
