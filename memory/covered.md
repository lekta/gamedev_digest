Парный PR #137130 «[NativeAOT] Split large arm64 code sections so the linker can place range-extension thunks (COFF and ELF)» прочитан своими руками: `created_at: 2026-11-07T08:54:44Z`, state open, merged false, +183/−44, 14 файлов, те же метки; режет секции примерно по 64 МБ на arm64 (8 МБ на arm) в COFF-писателе и arm64 ELF-писателе, правит обработку заглушек в hijacking, раскрутке стека и поиске unboxing-stub, тестирование — вручную на машинах Azure Cobalt 100. ВАЖНО: цитата из отчёта разведки про просьбу бэкпорта («This fix is needed in servicing too: shipped .NET 10 and 11 NativeAOT apps hit it on arm64 today.», комментарий 07.11 11:22 UTC) своими руками НЕ сверялась и в выпуск НЕ взята; бэкпорт-PR #137131/#137132/#137134/#137135/#137136 (по отчёту разведки открыты по ошибке и закрыты) тоже не сверялись.
