## 2026-09-23
- Content directories (22.09): блог Джорджа Инга — Unity называет их «более производительной и более гранулярной заменой AssetBundles», рантайм сам находит, грузит и выгружает отдельные меши и текстуры; новый тип ссылки `Loadable<T>` (`Loadable<Mesh> bodyMesh; bodyMesh.Load();`); доступно в Unity 6.6 для контента, идущего с плеером, удалённая доставка обещана в поколении Unity 7; проект на Addressables переезжает «with zero code changes», пример — Slime Rancher 2. [Unity](https://unity.com/blog/content-directories-beyond-the-assetbundle)
- Unity CLI 1.0.0-beta.11 (22.09): анонс christophera_unity — команда `unity recompile` проверяет компиляцию скриптов в запущенном редакторе без полной сборки, печатает файл и строку каждой ошибки, коды возврата 0 / 6 (ошибки компиляции) / 7 (редактор не отвечает); также `unity assets export`/`import` для `.unitypackage`, `unity docs` под версию проекта, `unity cloud org create`, чтение Build Automation и Pipeline Automation, `unity run --log-file`; починены заголовки сжатия WebGL-сборок, контрольные суммы Linux-модулей, Unity Connect и прокси; обновление `unity self-update`. [Unity Discussions](https://discussions.unity.com/t/unity-cli-1-0-0-beta-11-is-rolling-out/1737353)
- dotFly (22.09): Конрад Кокоса — движок инференса на .NET, коннектом дрозофилы (модель Shiu et al. 2024, leaky integrate-and-fire); 166 700 нейронов и ~25 млн синапсов у MaleCNS, `Vector256<float>` по 8 нейронов на инструкцию, SoA в неуправляемой памяти с выравниванием 64 байта (~2 МБ), ноль аллокаций на горячем пути, коннектом — memory-mapped `.dfb` в формате CSR; `[MethodImpl(MethodImplOptions.AggressiveOptimization)]` дал 21 → 6 мкс/шаг; 62 000 шагов/с на 8 потоках (6,2× реального времени), FlyWire 196 000 шагов/с (19,6×); GPLv3. [kokosa.dev](https://kokosa.dev/blog/2026/dotfly/)
- По диагонали: OZARK (22.09) — интервью Дэвида Жаньё (80.lv) со студией Alter Boy: шесть лет разработки, Unity 2022 LTS на Built-in Render Pipeline «по знанию пайплайна», из стороннего только NGSS для теней и решение для обратной кинематики; геймплейная архитектура, взаимодействие, поведение камеры, ИИ и внутренние инструменты свои; фиксированная 2.5D-перспектива — главное техническое бремя (своё прицеливание и захват цели, поведение врагов с оглядкой на край кадра); Blender, Cinema 4D, Substance Painter, Mixamo и мокап Vicon; игра на 3-6 часов. [80.lv](https://80.lv/articles/ozark-creating-a-dark-story-driven-2-5d-action-horror-game)
- По диагонали: DLSS 5 (22.09) — пост Филлипа Сингха: 3D-Guided Neural Rendering как финальный нейронный проход, на вход идут отрисованный движком кадр с геометрией, текстурами и буферами освещения плюс цвет и векторы движения, строгая схема «кадр на входе — кадр на выходе», до 4K, только RTX 50; первой везёт NBA 2K27 (Visual Concepts). RTX Kit 2026.3: Character Rendering 1.4, Dynamic Illumination 3.1 с DLSS Ray Reconstruction, Neural Texture Compression 0.10 beta, Neural Shading 1.4, Texture Filtering 1.3, Mega Geometry 2.0 со стримингом кластеров непрерывного LOD (Gears of War: E-Day). [NVIDIA](https://developer.nvidia.com/blog/whats-new-for-game-developers-dlss-5-with-3d-guided-neural-rendering-nvidia-ace-updates-and-new-rtx-kit-capabilities/)
- По диагонали: Metal Display Link на macOS (21.09) — при включённом `metalUseMetalDisplayLink` выход из окна и возврат намертво вешают игру, автор треда eMkaQQ, версия 6000.5.5; обход — переменная окружения `UNITY_USE_METAL_DISPLAY_LINK=0`, ответа Unity в треде нет; рядом сообщают об аналогичном зависании на iOS. - По диагонали: дамп памяти из своего процесса (22.09) — Аарон Пауэлл в блоге .NET: фоновый `ThreadPoolWatcher` кидает задачу в пул и меряет задержку, по превышению порога зовётся `MiniDumpWriteDump` из `dbghelp.dll` на Windows или утилита `createdump` плюс `prctl` на Linux; дампы в примере ~125 МБ на Windows и ~800 МБ на Linux; предупреждение про строки подключения и токены внутри. [.NET Blog](https://devblogs.microsoft.com/dotnet/creating-a-memory-dump-in-csharp/)
- По диагонали: BusEngine (23.09) — BuslikDrev на DTF: инициализация ядра своего движка на C# с ~500 мс до 30-50 мс, общий запуск втрое быстрее; вынос вызовов Windows API для консоли и логов в фоновый поток 50-80 мс, отказ от `dynamic` в пользу своего класса `BusEngine.Setting` с вложенными словарями ~200 мс, замена Newtonsoft.Json своим разбором без аллокаций; замеры на Acer Aspire 5, RX 550X, 8 ГБ, HDD. [DTF](https://dtf.ru/gamedev/5314130-optimizatsiya-dvizhka-busengine-na-cshar-i-okhrana-kotov-na-dache)
