Дословно подтверждено моим чтением: «A reload never touches call sites, fields, or type layout», «Coroutines already in flight keep the body they started with», «Interpreted code is slower than compiled code», «Domain reload isn't going anywhere for the changes that require it.». Запрещено внутри помеченных тел: `await`/`Task`, `try`/`catch`/`finally`, `lock`, LINQ query syntax, `checked`, `decimal`, `dynamic`, рефлексия и типы потоков, `ref`/`out`/`in`-параметры, генерик-методы, многомерные массивы; есть Roslyn-анализатор.
