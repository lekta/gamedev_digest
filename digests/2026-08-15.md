# GameDev Digest — 2026-08-15

Движок и язык сегодня молчат — свежих релизов нет, зато студии, где пишут код, показали, где у ИИ-ассистента спрятаны ручки. Visual Studio выдала Copilot переключатель усилия и ценник на каждую модель — теперь видно, за что платишь токенами. VS Code разрешил звать Claude по своему ключу, минуя вход в GitHub. В блоге .NET объясняют, что файл инструкций для агента — это бюджет, а не свалка. А в Phantom Blade Zero боёвку, оказывается, раскрутили из самого захвата движения. Показания собраны — разложу по порядку, вежливо.

### Visual Studio 2026 18.9 (11.08): у Copilot появилась ручка «сколько думать»

Обновление Visual Studio дало Copilot переключатель глубины рассуждений — низкий, средний, высокий — и показало цену, возможности и окно контекста каждой модели.

**Вывод.** Для C#/Unity-разработчика это прямой контроль над расходом токенов: автодополнению по asmdef хватит низкого уровня, разбору гонки в Job System нужен высокий — и заранее видно, во что обойдётся запрос.

**Детали.** Уровень усилия ставится прямо в выборе модели, там же — стоимость и закрепление любимых моделей. Добавили рабочие деревья Git (несколько веток проекта параллельно без stash), проверку незакоммиченного кода агентом с комментариями в редакторе и свои агенты на уровне организации. Релиз — 11 августа. [Microsoft Learn](https://learn.microsoft.com/en-us/visualstudio/releases/2026/release-notes)

### VS Code 1.133 (12.08): Claude по своему ключу, без входа в GitHub

Обновление VS Code разрешило открывать окно агентов по собственному ключу Claude без входа в аккаунт GitHub и менять провайдера модели между ходами.

**Вывод.** Кому недоступен github.com или неудобна подписочная привязка — можно гонять агента напрямую по API-ключу; смена провайдера по ходу диалога экономит: дорогую модель зовёшь только на сложный шаг.

**Детали.** Экспериментальная настройка открывает агентов без входа в GitHub при уже настроенном ключе Claude; в выборе модели рядом стоят варианты Anthropic и Copilot. Один сеанс питает несколько окон редактора (Agent Host Protocol), а агент Copilot выровнен с Copilot SDK между командной строкой, приложением и VS Code. Релиз — 12 августа. [VS Code](https://code.visualstudio.com/updates)

---

- **Microsoft / .NET (12.08): файл инструкций для ИИ-агента — это бюджет, а не свалка** — в блоге .NET советуют держать в инструкциях только то, что меняет результат и что модель сама не выведет: неочевидные архитектурные границы, проверенные команды сборки, осознанные локальные решения, жёсткие ограничения; выкинуть общие «пишите чисто», полные списки папок и «театральные» уговоры модели. Приём — ревизия «оставить/убрать/перенести/проверить»; примеры на .NET, но принцип общий для любого ИИ-ассистента. [.NET Blog](https://devblogs.microsoft.com/dotnet/instructions-hygiene-what-frontier-models-still-need-you-to-say/)
- **S-GAME / Phantom Blade Zero (14.08): боёвку строили от захвата движения, а не наоборот** — креативный директор Соулфрейм Лян рассказал, что механику лепили прямо из mocap-сессий Донни Йена и каскадёров, снятых на полной боевой скорости, а реакции боссов проектировали под длину комбо (по-разному на связку из четырёх и пяти ударов). Движок в материале не назван; мораль для боёвки на любом движке — хит-реакции суть производная от данных захвата, а не декор поверх готовой логики. [80.lv](https://80.lv/articles/phantom-blade-zero-uses-authentic-kung-fu-motion-capture)
- **Downtown Generator V2 (14.08): процедурный центр города для Blender** — Мохамед Эльшериф выпустил вторую версию генератора: облегчённый режим, генерация отдельных кварталов, 180+ модульных зданий и 50+ пропсов, требуется Blender 5.0+. Для Unity-сцены — быстрый источник городского окружения на экспорт, но геометрию и материалы потом придётся оптимизировать под движок. [80.lv](https://80.lv/articles/procedural-american-downtown-generator-for-blender)

Из прошлого: автодополнение IntelliSense — подсказку по членам типа прямо в редакторе — Microsoft показала в Visual Basic 5.0 и Visual C++ 5.0 (1997), и оно быстро стало причиной, по которой разработчики держались за среду, а не за один компилятор. Двадцать девять лет спустя та же подсказка в Visual Studio обзавелась переключателем «сколько думать» и ценником в токенах — эволюция от «допиши слово» к «порассуждай за деньги».
