# GameDev Digest — 29 октября 2026

Ночной эфир, определитель номера исправен. Первый звонок из Unity: публичный репозиторий Input System сегодня перевели в режим поддержки, внешние правки больше не принимают. ### Unity (29.10): Input System закрыли от внешних правок
Новость: с Unity 6.7 пакет разрабатывают во внутреннем репозитории, публичный переведён в режим поддержки.
**Вывод.** Свой фикс в Input System теперь не влить: форк для себя лицензия разрешает, но путь в сам пакет остался один — баг-репорт.
**Детали.** PR #2501 автора josepmariapujol-unity влит 29 октября в 11:01 UTC, затронуты три файла. В README появилось «Starting with Unity 6.7, Input System development has moved to an internal Unity repository», а бэкпортят сюда теперь «only fixes for critical bugs and issues that cause high user pain». В CONTRIBUTIONS.md прежние правила оформления правок заменены отказом: внешние pull request закрывают без ревью, баги идут в Unity Bug Reporter, вопросы и просьбы о фичах — в Unity Discussions. [GitHub](https://github.com/Unity-Technologies/InputSystem/pull/2501)

### Mono на ARM64 (28.10): две гонки в трамплинах, найденные по падениям на Android
Новость: внешний разработчик разобрал редкие нативные падения C#-приложения на Pixel 6a и принёс два тикета в dotnet/runtime.
**Вывод.** Если мобильная сборка падает в нативном коде без управляемого исключения, причина может быть не в вашем коде: оба места — в рантайме, на котором работает Mono-бэкенд Unity.
**Детали.** В issue #136582 автор mhwang-sd пишет, что 64-битный литерал адреса в JIT-трамплине бывает выровнен по 4 байта вместо 8, а трамплин перенаправляют на уже исполняющемся коде — отсюда гипотеза о разорванном чтении; его зонд насчитал 1555 невыровненных литералов на 2939 наблюдений, с собственной правкой — ноль. В issue #136583 указатель на метод и invoke-заглушка делегата пишутся без барьера, и конструктор делегата может увидеть новую заглушку при ещё нулевом указателе. Автор сам отмечает, что воспроизведения нет и причина не доказана; оба тикета открыты и помечены untriaged. [GitHub](https://github.com/dotnet/runtime/issues/136582)

### Клоны инди-игр (28.10): оригинал обошли по вишлистам, Valve фильтровать не станет
Новость: разбор по данным Steam показал, как копия раскрученной инди-игры опередила оригинал, пока тот держал закрытый плейтест.
**Вывод.** Закрытый плейтест и тихий релиз от копирования не спасают, зато лишают витрин Steam — играбельное демо выгоднее выпускать рано.
**Детали.** Крис Зуковски разобрал жанр «найди иголку в стоге сена»: на плейтест оригинала Needle In A Haystack Simulator записались 23 000 человек, а клон Find The Needle с открытым демо обошёл его по фолловерам 5 октября и, по оценке автора, идёт примерно на 20 000 вишлистов впереди при росте оригинала в 60–70 фолловеров в день. Планку в 100 фолловеров во всём жанре перешли три игры. На конференции в Пусане представители Valve, по пересказу InvenGlobal, сказали «We don't want to be gatekeepers telling developers which tools they should or shouldn't use» — отбирать клоны платформа не собирается. [How To Market A Game](https://howtomarketagame.com/2026/10/28/ai-cloners-are-here-are-indie-devs-cooked/), [Game Developer](https://www.gamedeveloper.com/pc/valve-addresses-steam-ai-cloning-problem)
