Valve, как и ожидалось, напомнила правила Artwork Override: скидки и призывы добавить в желаемое на обложке снимут досрочно. У One-armed Robber увели ключ Steamworks API, и взломщик, разумеется, раздал игрокам возвраты и баны. Microsoft переписала приложение на .NET MAUI в два нативных силами агентов: вышло быстро, но дорого по времени моделей.

### Steam (19.11): Artwork Override — только про новый играбельный контент
![Steamworks](https://clan.fastly.steamstatic.com/images/4145017/8d97562f419d0a2762fbbf39dddd8f155659e53d.jpg)
Valve пишет, что в последние недели стало больше Artwork Override с нарушениями, и напоминает требования.
**Вывод.** Анонс DLC или крупного обновления через подменную обложку нужно сверить с правилами до запуска. Иначе арт снимут или завершат раньше срока.
**Детали.** Override разрешён [«только для рассказа об играбельном контенте в игре»](https://store.steampowered.com/news/group/4145017/view/696529069521503099#:~:text=only%20for%20communicating%20about%20playable%20in%2Dgame%20content): новый персонаж, DLC, добавленный мультиплеер. Нельзя рекламировать демо или сиквел, [«не указывайте скидку на обложке»](https://store.steampowered.com/news/group/4145017/view/696529069521503099#:~:text=Do%20not%20list%20a%20discount%20in%20your%20artwork), нельзя надписи вроде «Wishlist Now» и «Now Available». Название игры должно оставаться самым крупным и читаемым текстом.

### One-armed Robber (вчера): чужой ключ Steamworks API — возвраты и баны игрокам
![One-armed Robber](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/2551020/header.jpg)
Кто-то получил один из ключей Steamworks API небольшой студии и банил им игроков и возвращал деньги за покупки в игре.
**Вывод.** Ключ издателя Steamworks Web API даёт доступ к транзакциям и банам. Держите его только на своём сервере, не в клиенте и не в репозитории, и отзывайте при первом подозрении.
**Детали.** По пересказу Dexerto, [«возвраты получили игроки, которые никогда не просили вернуть деньги»](https://www.dexerto.com/gaming/devs-of-steam-heist-game-robbed-irl-as-hacker-refunds-players-in-game-purchases-3430127/#:~:text=The%20refunds%20went%20to%20players%20who%20had%20never%20asked), и команда понесла значительные убытки. Ключ отозван, баны сняты. Разработчики выставили карты ограблений на распродажу и попросили игроков по желанию потратить часть возврата снова.

### .NET MAUI (вчера): агенты переписали приложение в два нативных за четыре часа работы автора
![Barista Notes](https://devblogs.microsoft.com/dotnet/wp-content/uploads/sites/10/2026/11/baristanotes-hero.webp)
Дэвид Ортинау из команды .NET MAUI отдал агентам Copilot переписать Barista Notes на отдельные .NET for iOS и .NET for Android.
**Вывод.** Агенты удешевляют отдельный UI под каждую платформу, но координация стоит больше самой реализации. Общий UI автор всё равно оставляет точкой старта.
**Детали.** Первый проход занял меньше четырёх часов его времени, а координирующий агент [«потратил больше времени моделей, чем обе версии вместе»](https://devblogs.microsoft.com/dotnet/ai-cross-platform-decision-matrix/#:~:text=used%20more%20model%20time%20than%20both%20versions%20combined): 616 минут против 209. С ReadyToRun запуск на Android ускорился с 1233 до 615 мс, на iOS — с 569 до 367 мс. Работали 13 агентов, в основном на GPT-6 Astra.
