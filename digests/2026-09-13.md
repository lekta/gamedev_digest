# GameDev Digest — 13 сентября 2026

Сводка о том, что не доводится до конца. Новый ContentDirectory в Unity 6.6 грузит ассеты проще Addressables, но отменить начатую загрузку нечем — в кооп-шутере приходится дождаться ненужного оружия и только потом взять нужное. Union-типы C# 15 в ASP.NET Core работают везде, где данные идут через JSON, и не работают нигде больше — ни в строке запроса, ни в заголовках, ни в формах. Индексатор на Roslyn отдаёт кодовому агенту точный граф вызовов — на живом репозитории граф вышел в 600 мегабайт. Конец у всего обычно один, но подробности я всё же приведу.

### ContentDirectory в Unity 6.6 (сегодня): начатую загрузку нечем отменить

В ветке обсуждения нового способа доставки контента снова попросили поддержку отмены загрузки.

**Вывод.** Если смотришь на ContentDirectory как на простую замену Addressables, учти главный пробел: токена отмены нет, и при быстрой смене объектов ты платишь лишними чтениями с диска и памятью.

**Детали.** Ветку 29.07 начал JesOb, оценив новый API как «в сто раз проще Addressables»: дедупликация без настройки, инкрементальная пересборка, выгрузка отдельного ассета без привязки к бандлу. 13.09 XaneFeather принёс кейс кооперативного шутера, где игроки быстро переключают оружие: без отмены загрузчик обязан дождаться, пока догрузится и освободится ставший ненужным ствол, и только после этого начать следующий. Сотрудник Unity Joseph 02.08 пояснил, что в 6.6 поддержаны статические директории, поставляемые вместе с игроком, а динамическая доставка будет позже. Отдельное ограничение от автора ветки: подменить ассет в директории можно, только если новый файл байт в байт того же размера — то есть HD-моды и патчи мимо. [Unity Discussions](https://discussions.unity.com/t/new-unity-6-6-contentdirectory-good-and-bad-q-a/1732493)

### Union-типы C# 15 (10.09): живут только там, где ходит JSON

Microsoft впервые расписала, в каких местах ASP.NET Core новые union-типы работают, а в каких нет.

**Вывод.** Union-тип живёт только там, где данные идут через JSON: в теле запроса и ответа, у SignalR и Blazor — да; в строке запроса, маршруте, заголовках и формах — нет вообще, и это ограничение проектируется заранее, а не обходится атрибутом.

**Детали.** Дмитрий Королёв из команды языков и фреймворков: `JsonSerializer.Serialize(new UnionIntString(42))` пишет просто `42`, без обёртки и без метки варианта; у Minimal API и MVC union-типы годятся и для входа, и для возврата, включая `Task<TUnion>`, у SignalR их тянет `JsonHubProtocol` без настройки, в OpenAPI они дают схему `anyOf` по одному пункту на вариант. Цена отсутствия метки известна с разбора Эндрю Лока от 01.09: три варианта одинаковой формы при чтении дают отказ по неоднозначности, и различать их приходится своим `JsonTypeClassifierFactory<T>`. Релиз .NET 11 — 10 ноября. [.NET Blog](https://devblogs.microsoft.com/dotnet/unions-and-closed-hierarchies-in-aspnetcore/), [andrewlock.net](https://andrewlock.net/exploring-the-dotnet-11-preview-7-the-pain-of-serializing-unions-and-closed-class-hierarchies-with-system-text-json/)

### Graphify C# (12.09): поиск использований от компилятора — для кодовых агентов

Вышел открытый индексатор на Roslyn, который выгружает граф символов C#-решения в JSON.

**Вывод.** Агенту в проекте больше не нужно угадывать по текстовому поиску, кто вызывает метод: точные вызовы, ссылки, наследование и реализации читаются из файла, без запущенной IDE в фоне.

**Детали.** Автор — zachsaw, лицензия MIT, ставится как глобальный инструмент командой `dotnet tool install --global Graphify.CSharp --framework net10.0`; обходит `.sln` и `.csproj` без собранных сборок, поддерживает C# 14 на .NET 10 и предварительный C# 15 на .NET 11, наблюдатель за файлами держит рабочее пространство Roslyn тёплым. Автор честно оговаривает границы: рефлексия, внедрение зависимостей и динамические вызовы в граф не попадают, а ноль входящих ссылок означает ноль найденных статически, а не мёртвый код. На его собственном репозитории выгрузка перевалила за 600 МБ. [GitHub](https://github.com/zachsaw/graphify-csharp), [Show HN](https://news.ycombinator.com/item?id=49667188)
