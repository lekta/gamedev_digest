# GameDev Digest — 2026-08-05

Вскрытие показало: в бете Unity 6.6 (сборка b6, 04.08) вычищают мёртвые API — `Component.rigidbody` удалён совсем, полсотни методов вокруг `InstanceID` списаны в пользу `EntityId`, — и на освободившемся месте 2D-физике добавили плавучесть и ветер. По протоколу день ровный: Microsoft показала на C# распознавание речи прямо на устройстве, без облака. А один пациент, которого давно списали, задышал — XNA переписали на C++. Живой — приятная неожиданность.

### Unity 6.6 beta (b6, 04.08): чистка старых API и силы в 2D-физике

Вышла свежая бета ветки 6.6 — с удалением наследия и апгрейдом 2D-физики.

**Вывод для тебя.** Проект тянется с ранних Unity 6 — заложи время на правки. `Component.rigidbody` и `GameObject.rigidbody` удалены полностью, без автозамены; 50+ методов вокруг `Object.GetInstanceID`/`Resources.InstanceIDToObject` помечены устаревшими в пользу `EntityId`; Dynamic Batching выпилен целиком («мало толку на современном железе»). Зато 2D-физика получила плавучесть и ветер через `PhysicsBody`/`PhysicsWorld` и тип `PhysicsSpace` для своих broad-/narrowphase-запросов.

**Детали.** В DOTS: managed-компоненты под удаление, `EntityCommandBuffer` — только одиночное воспроизведение (multi-playback устарел), новые `IOnAdded`/`IOnRemoved`. GPU Resident Drawer научился инстансить mesh LOD; дефайны `UNITY_64` и `DEVELOPMENT_BUILD` устаревают с предупреждениями. В бете 4 активных блокера (краши входа в Play Mode с выключенным Reload Domain и др.). [unityreleases.com](https://unityreleases.com/releases/6000.6.0b6)

### Локальная речь-в-текст на C# (04.08): голос без облака

Microsoft показала консольное C#-приложение, которое распознаёт речь с микрофона в реальном времени прямо на устройстве.

**Вывод для тебя.** Голосовой ввод для NPC или команд можно повесить на чистый C#-конвейер, который крутит распознавание локально — без сети, без оплаты за токены. Это готовая референс-заготовка под голосовых персонажей; в Unity «из коробки» пока не ляжет (нужен .NET 10 и Windows ML), но пайплайн и модель переносимы по смыслу — как раз к волне on-device AI-компаньонов.

**Детали.** .NET 10, модель NVIDIA Nemotron 0.6B (потоковый ASR, английский), жизненный цикл через `Microsoft.AI.Foundry.Local.WinML`, микрофон через NAudio (16 кГц, 16 бит, моно PCM). API совместим с OpenAI Realtime; выдаёт промежуточные и финальные результаты по мере речи. Пока только Windows (зависимость от WinML). Автор — Bruno Capuano. [.NET Blog](https://devblogs.microsoft.com/dotnet/foundry-local-live-speech-to-text-csharp/)

- **CNA (04.08): XNA переписали на C++.** Проект CNA — реализация API Microsoft XNA 4.0 на C++23 поверх SDL3, лицензия Ms-PL. Уже покрыто 92,7% публичных типов XNA (227 из 245), восемь графических бэкендов (Vulkan, bgfx, WebGPU, D3D9-12, даже ASCII), сеть через ENet. Для C#-лагеря это не инструмент, а контекст: XNA-модель, породившая MonoGame и FNA, теперь есть и в неуправляемом C++ для тех, кому нужен контроль над рантаймом. 55★. [GameFromScratch](https://gamefromscratch.com/cna-its-c-xna/), [GitHub](https://github.com/openeggbert/cna)
- **NuGet (03.08): срок жизни API-ключей режут до 30 дней.** С 17.08 новые ключи публикации — максимум на 30 дней (было 365), а все ключи, созданные до этой даты, отключат 01.11. Если у тебя CI постит пакеты в NuGet.org — проверь пайплайны и заведи ротацию, а лучше переезжай на Trusted Publishing (OIDC, короткоживущие токены без хранения секрета). Повод — атаки на цепочку поставок вроде компрометации NX Console (6000 установок за 36 минут). [.NET Blog](https://devblogs.microsoft.com/dotnet/strengthening-nuget-supply-chain-security-reducing-api-key-lifetime/)
- **80.lv (04.08): AI-вывод превращают в кисти ZBrush.** Дмитрий Безродний разобрал сборку персонажа Ариадны в крито-микенском стиле: пропорции правил через MetaHuman, одевал 3D-скан, а результат генеративной модели прогонял в рабочие кисти ZBrush. Пример живого гибрида «скан + MetaHuman + ручная скульптура», где AI сидит инструментом в пайплайне, а не заменяет художника. [80.lv](https://80.lv/articles/creating-a-detailed-and-expressive-character-inspired-by-cretan-mycenaean-culture)

**Из прошлого.** XNA (Microsoft, 2006–2013) — управляемый C#-фреймворк для игр под Windows, Xbox 360 и Zune, на котором выросли Bastion, Terraria и Stardew Valley. Microsoft свернула его в 2013, но сообщество не дало умереть: MonoGame и FNA перенесли тот же API на современные платформы. Теперь к ним прибавился и C++-двойник — редкий случай, когда «покойника» вскрывают спустя тринадцать лет, а он ещё бегает.

## На горизонте

Раз уж сегодня Microsoft дала C# голос на устройстве — на очереди тот же приём в игровом теле: бета NVIDIA ACE Game Agent SDK и PUBG Ally держат локального AI-напарника на потребительской видеокарте, и вопрос, что из этого собирается поверх Unity Inference Engine. Рядом лежит физика: Box3D Эрина Катто и Jolt 5.6 напрашиваются на очную ставку со штатной физикой Unity — тем громче на фоне свежих сил в 2D-физике 6.6. Из графического стека под Linux ждём стабильный Mesa 26.2 с DLSS в открытом драйвере NVK — тест на паритет апскейла для SteamOS-сборок. И тянется вопрос к C# 15: закрытые union-типы боксируют значения при каждом присваивании — надо померить, насколько это больно на горячих путях игрового кода.

Держите инструменты острыми, а швы — ровными.
