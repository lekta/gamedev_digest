### Halo: Campaign Evolved (сегодня): ремейк первой Halo на Unreal 5 — дебют MegaLights в большой игре
![Halo: Campaign Evolved](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/2806050/9470157e11a7b26c49236ed692cf822cb06fc1b4/ss_9470157e11a7b26c49236ed692cf822cb06fc1b4.1920x1080.jpg?t=1784829117)
Halo Studios переиздали кампанию Halo: Combat Evolved на Unreal Engine 5, отправив собственный движок Slipspace на покой.
Для тебя это витрина того самого динамического света, к которому Unity подбирается через Surface Cache GI: аппаратный Lumen плюс MegaLights на десятки тысяч источников — удобная планка, чтобы оценить свой рендер на URP/HDRP.
Детали: релиз сегодня на PC/Xbox Series/PS5 (Halo впервые на PlayStation), $49.99, кооп до 4 с кросс-игрой и кросс-прогрессом. По тех-разборам — один из первых крупных тайтлов с MegaLights и аппаратным Lumen. В Steam 71% из ~3,4 тыс. отзывов положительные; мультиплеера нет, только кампания и три новые миссии. [Steam](https://store.steampowered.com/app/2806050/Halo_Campaign_Evolved), [тех-разбор Playfront](https://playfront.de/en/halo-campaign-evolved-im-tech-check-unreal-engine-5-glaenzt-auf-der-ps5-pro/)

### .NET: Copilot разбирает журналы сборки MSBuild прямо в VS Code (27.07)
Microsoft выпустила в превью расширение MSBuild Binlog Analyzer для VS Code — Copilot читает бинарный лог сборки (.binlog) и объясняет, почему она упала.
Вместо ручного копания в шумных логах NuGet-restore получаешь причину простым языком и правку в один клик; заодно видно самые медленные цели и критический путь — полезно, когда C#-решение собирается долго.
Детали: нужны VS Code 1.99+, GitHub Copilot и .NET SDK. Под капотом — MCP-сервер Microsoft.AITools.BinlogMcp (ставится сам при первом запуске), дающий Copilot десятки инструментов анализа лога. Можно назначить базовый лог и сравнивать с ним каждую новую сборку, чтобы ловить регрессии. [.NET Blog](https://devblogs.microsoft.com/dotnet/msbuild-binlog-analyzer-vscode/), [Marketplace](https://marketplace.visualstudio.com/items?itemName=dotutils.binlog-analyzer)

[80.lv](https://80.lv/articles/full-body-hand-facial-motion-capture-from-any-video-in-blender)

## На горизонте
На подходе сказки посерьёзнее. Сторонние физдвижки Jolt и Box3D примеряются к штатной физике Unity — Godot уже сделал Jolt дефолтным, так что вопрос «почему у Unity только через обёртки» стоит ребром. Unity 6.7 alpha уже собирает Player на CoreCLR — скоро видно будет, что из DOTS/Burst/IL2CPP переживёт уход Mono. Союзные типы в C# 15 хороши на бумаге, но втихую боксируют значения — колется на горячих путях игрового кода. А гауссовы сплаты дозревают до настоящего контента: чем их тащить в Unity и почём на боевой сцене.
