# GameDev Digest — 10 сентября 2026

Ночь выдалась разговорчивой. Unity выложила официальный плагин для Claude Code — 29 инженерных навыков, свой CLI и MCP-сервер к живому редактору; заодно баннер в Hub так неудачно это прорекламировал, что форум прочитал текст как «за вашей системой контроля версий следит агент». JetBrains тем временем нашла виновника медленного старта Rider — им оказался Defender, а не IDE. И тихо, без объявлений: Unity 6.7 в альфе убрала `libmain.so`, и на Quest 3 сборка перестала доходить даже до заставки движка.

### Unity × Claude Code (09.09): официальный плагин с 29 инженерными навыками

![Unity plugin for Claude Code](https://cdn.sanity.io/images/fuvbjjlp/production/27fbaaaad054e76728f21d5349c429349a817927-1920x1080.png)

Unity выпустила официальный плагин для Claude Code: набор инженерных навыков, Unity CLI и MCP-сервер управления редактором.

**Вывод.** У агента появляется штатный путь к живому редактору вместо самодельного MCP-моста — ставится одной командой, без настройки под каждый проект и без переноса конфигов между машинами.

**Детали.** На старте 29 навыков по девяти областям: начало работы и инструментарий, интерфейс и текст, 2D и спрайты, графика и рендеринг, звук, сцена и геймплей, монетизация и LiveOps, мультиплеер, платформы и локализация. Claude Code назван первым агентом, остальные обещаны до конца года. Тот же плагин рекламировал баннер в Hub 3.21.1, и PeachyPixels принял его за слежку; christophera_unity в тот же день ответил, что Hub не смотрит в систему контроля версий дальше базовых статусов и никаких агентов там нет, а формулировку поправят. [Unity Blog](https://unity.com/blog/unity-plugin-for-claude-code), [Unity Discussions](https://discussions.unity.com/t/1736196)

### Rider и ReSharper (09.09): долгий старт объяснился антивирусом

JetBrains и Microsoft выяснили, что ReSharper вне основного процесса тормозил на запуске из-за Defender.

**Вывод.** Defender мягче сканирует то, что лежит в защищённом от записи каталоге — а Toolbox ставит Rider в пользовательскую папку, и это стоит десятков секунд на каждом старте.

**Детали.** По замерам Александра Улитина (JetBrains) и Майкла Хокера (Microsoft) сканирование отдельного процесса ReSharper занимало около 50 секунд против примерно 2 секунд у встроенного варианта; IDE самой Microsoft и VS Code укладывались в секунду, инструменты командной строки — в две. Ловили через ETW-провайдер `Microsoft-Antimalware-Engine` и командлеты `New-MpPerformanceRecording` / `Get-MpPerformanceReport`, попутно выложив открытый Defender Performance Tool. В Defender 1.449.454.0 время упало ниже 5 секунд для установки в защищённый каталог, но у Rider из Toolbox осталось 44 секунды. [JetBrains .NET Blog](https://blog.jetbrains.com/dotnet/2026/09/09/why-rider-and-resharper-were-slow-to-start-and-how-microsoft-helped-fix-the-problem/)

### Unity 6.7 alpha (08.09): убрали libmain.so — сборка не стартует на Quest 3

В альфе 6000.7.0a6 сменился способ загрузки нативных библиотек на Android, и IL2CPP-сборка перестала запускаться на Meta Quest 3.

**Вывод.** Точка входа на Android теперь другая — это задевает всех, кто собирает под Android, и в первую очередь тех, кто грузит движок из собственного Java-кода.

**Детали.** В релиз-нотах 6000.7.0a6 сказано, что `libmain.so` удалён, а `libunity.so` и `libil2cpp.so` грузятся напрямую слоем Java — чтобы убрать повторный вызов `JNI_OnLoad` при перезагрузке рантайма. DavidZobrist1 сообщает: тот же проект на 6000.7.0a5 стартует, на a6 виснет на загрузочном экране Meta и не доходит до заставки Unity; Android ARM64, IL2CPP, OpenXR 1.18.0, откат обновлений пакетов не помог. Ответа Unity в треде нет. [Unity Discussions](https://discussions.unity.com/t/il2cpp-player-crashes-at-startup-23765/1736040), [релиз-ноты](https://unity.com/releases/editor/alpha/6000.7.0a6)

---

- **UI Toolkit (08.09): экспериментальные UI Components в 6.7 Alpha 6** — сотрудник Unity uMathieu впервые расписал недокументированную модель: данные и логика цепляются к `VisualElement` через размеченные структуры, glue-код генерируется исходниками. Включается в Project Settings → UI Toolkit → Enable UI Components; атрибуты уровня структуры `[VisualElementComponent]`, `[RequiresElementOfType]`, `[RequiresComponentOfType]`, методов — `[RegisterCallback]`, `[GenerateVisualContent]`, `[OnComponentChanged]` и другие. Ограничения жёсткие: только структуры без наследования, один компонент каждого типа на элемент, любое управляемое поле тянет за собой аллокацию в куче. [Unity Discussions](https://discussions.unity.com/t/1735679)
- **.NET (08.09): сервисные обновления закрыли восемь уязвимостей** — вышли .NET 10.0.12, 9.0.20 и 8.0.31 с правками рантайма, ASP.NET Core и EF Core; CVE-2026-69522 задевает вдобавок .NET Framework 4.6.2-4.8.1, для которого выпущено накопительное обновление. Тем, у кого на .NET живёт серверная часть или билд-инфраструктура, обновляться стоит сразу. [.NET Blog](https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-september-2026-servicing-updates/)
- **DLSS5VKLayer (08.09): DLSS 5 на Linux через прослойку Wine** — открытый неявный слой Vulkan перехватывает кадры, передаёт их по межпроцессному каналу windows-помощнику NGX под Wine или Proton и возвращает обработанный кадр обратно в цепочку показа; векторы движения считает NVIDIA Optical Flow, опционально подключается Smooth Motion. Нужны проприетарный драйвер и вытащенные вручную библиотеки NGX; есть графическая оболочка на Qt и вариант для командной строки. [Phoronix](https://www.phoronix.com/news/DLSS5VKLayer)
- **Hardcraft (09.09): бесплатная ретопология CAD-моделей в Blender** — альфа-аддон Виталия Яблонского читает уцелевшую в экспорте структуру CAD (файлы STEP, выгрузки Plasticity Blender Bridge), режет поверхность на патчи и кривые и даёт настраивать сетку по каждому патчу отдельно, смешивая четырёхугольники и треугольники. Требует Blender 5.0 и новее, исходники и сборки лежат на GitHub. [80.lv](https://80.lv/articles/try-this-free-cad-data-retopology-tool-for-blender)

## На горизонте

Из ближайшего: Jagex открыла добровольную бету Vulkan-бэкенда вместо OpenGL в двадцатилетней MMO — редкий публичный случай замены графической подложки на живом сервисе, и ждём замеров до и после. Дальше — потолок WebGL с Memory64 в 6.7, где рантайм умирает на 15,59 ГиБ при выставленных 128 ГБ, и вопрос, чей это предел: движка, Emscripten или браузера. Ещё в очереди — HDRP, где `storageIndexForFrustumPlanes` ссылается на чужое поле и разные наборы теневых запросов делят один диапазон памяти. И публичная телеметрия по ботоводству в Delta Force: 147 717 случаев автоматизации за неделю против 110 перехватов аппаратных читов — редкий случай, когда студия считает не аимботы, а урон экономике.
