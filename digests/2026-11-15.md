# GameDev Digest — 15 ноября 2026

Выходные, официальные блоги молчат — зато ломается само, и это даже удача: сразу видно, обо что спотыкаешься. На свежей Windows 11 защита Smart App Control блокирует неподписанные файлы Unity, редактор уходит в Safe Mode, а сегодня в теме дописали, что под раздачу попал и Burst. Unity вчера выложила исходники Bagel Express — игры целиком на UI Toolkit, без единой картинки и без единого звукового файла. В .NET 11 инлайнер раздул горячий цикл вдвое и затормозил его на 20–50%. Старьё, притворяющееся новостями, в эфир не пустил — разбираем живое.

### Unity (сегодня): Smart App Control уводит редактор в Safe Mode, теперь и через Burst
Новость: Windows 11 блокирует неподписанные DLL редактора, и Unity не входит в play mode.
**Вывод.** Если на свежей Windows 11 редактор валится в Safe Mode с ошибкой сборочной системы, проект тут не виноват: защиту надо выключить, пока Unity не подпишет свои файлы.
**Детали.** Автор темы поймал `System.IO.FileLoadException` на `Bee.TundraBackend.dll`, код выхода BuildProgram `-532462766`, а `Get-AuthenticodeSignature` показал статус `NotSigned`; воспроизводится и на 6.3 LTS. 13 ноября сотрудник Unity Tautvydas-Zilys подтвердил: «This is a bug, all files Unity installs should be signed». Сегодня в теме добавили, что то же ломает Burst — он генерирует локальную DLL, проверить которую нечем, — и что на 6000.6.9f1 при включённой защите не стартует IntelliSense, если открывать C#-файл из редактора. [Тема на форуме Unity](https://discussions.unity.com/t/bee-tundrabackend-dll-not-signed-in-6000-6-8f1/1741454)

### Unity (14.11): витрину UI Toolkit выложили в открытый доступ — без единой картинки
![Bagel Express](https://raw.githubusercontent.com/Unity-Technologies/BagelExpress/master/Docs/home.png)
Новость: Unity опубликовала исходники Bagel Express, игры, собранной целиком на UI Toolkit.
**Вывод.** Это рабочий справочник по тому, что UI Toolkit умеет с 6.4 по 6.7: в проекте есть окно, где каждая фича идёт с живым примером, сниппетами и перечнем мест в игре, где она применена.
**Детали.** В README дословно: «no image or audio assets» — графика собрана из градиентов, теней и фильтров USS, SVG, Painter2D, mesh modifiers и UI Shader Graph, а каждый звук синтезируется в момент проигрывания. Нужен 6000.7.0b9 или новее: игра использует `box-shadow`, которого в b8 ещё нет. В журнале изменений от 14 ноября проект уже собран на 6000.7.0b10, хотя публично свежайшая бета — b9 от 11 ноября. [Bagel Express на GitHub](https://github.com/Unity-Technologies/BagelExpress)

### C# (14.11): в .NET 11 инлайнер раздувает горячий цикл и теряет девиртуализацию
Новость: на том же IL Tier1 в .NET 11 выдаёт вдвое больше кода для цикла записи и работает на 20–50% медленнее.
**Вывод.** Переход на .NET 11 может просадить горячий цикл без всякой вины кода, и причина — бюджет инлайнинга: прежде чем переписывать логику, стоит проверить `DOTNET_JitInlineBudget`.
**Детали.** Медиана на операцию: Ryzen 9 5900X 927 → 1132 мкс, Xeon Platinum 8370C 1076 → 1593 мкс, EPYC 7763 1255 → 1641 мкс. Размер кода Tier1 для метода `WriteCore` вырос с 2919 до 6346 байт, число инлайнов — с 28 до 116. .NET 11 втягивает в цикл крупный форматтер записи и перестаёт инлайнить маленький `TextWriter.Write(ReadOnlySpan<char>)`, который выбрала guarded devirtualization. С `DOTNET_JitInlineBudget=5` .NET 11 обгоняет .NET 10: 891 мкс против 927. [Issue dotnet/runtime #137552](https://github.com/dotnet/runtime/issues/137552)
