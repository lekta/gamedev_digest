# GameDev Digest — 2026-09-18

Команда Harbour Masters призналась, что годами писала код своих портов с ИИ-ассистентами, и не смогла назвать версию, где его нет. Unity тем временем открыла публичную бету 6.7, будущего LTS, и выключила статический батчинг в новых проектах. А в The First Descendant одним патчем сняли клиентский античит и открыли торговлю лучшим оружием — такие совпадения я по привычке записываю в протокол отдельной строкой.

### Unity 6.7 Beta (вчера): открыта публичная бета следующего LTS

Unity выложила первую публичную бету ветки 6.7 — 6000.7.0b1, с еженедельными сборками до релиза.

**Вывод.** Статический батчинг в новых проектах теперь выключен по умолчанию, а нижняя планка iOS/tvOS поднята до 16.0 — оба изменения меняют поведение свежесозданного проекта, а не только настройки.

**Детали.** В ветке появились экспериментальные сборки плеера на CoreCLR под Windows, macOS и Linux; в Entities удалены управляемые API компонентов, устаревшие ещё в 6.6, и сняты покадровые выделения памяти в `ComponentSystemGroup`; Netcode for Entities стал обычным пакетом вместо встроенного. Добавлены пакеты `com.unity.steam.platform@1.0.0`, `com.unity.steamworks-api@1.0.0-pre.1` и `com.unity.2d.physics@1.0.0`. В известных проблемах висят падение IL2CPP-плеера на старте (UUM-148475) и дедлок при выходе из Play Mode (UUM-152966). [Объявление](https://discussions.unity.com/t/unity-6-7-beta-is-now-available/1736830), [релиз-ноты](https://unity.com/releases/editor/beta/6000.7.0b1)

### Ship of Harkinian (вчера): авторы порта не могут назвать версию без ИИ-кода

![Ocarina of Time](https://kotaku.com/app/uploads/2026/07/ocarina-of-time-link.jpg)

Команда Harbour Masters подтвердила, что годами писала код своих портов с помощью ИИ-ассистентов.

**Вывод.** Если происхождение кода не помечено в истории, вопрос «какие куски проверял человек» через год остаётся без ответа — это аргумент фиксировать инструмент прямо в сообщении коммита, а не в памяти сопровождающего.

**Детали.** Названы Claude, GitHub Copilot и ChatGPT; сильнее всего задет рантайм-слой libultraship. Разработчик Malkierian объяснил, что множество функций «конвертировали скриптом, написанным с помощью ИИ, с последующей проверкой на паритет»; на вопрос, какая версия свободна от ИИ-кода, разработчик Briaguya ответил «I don't know». Разработчик Jeod объясняет происходящее тем, что людей мало, а поддерживаемых портов много. Разошлось всё с поста на PCGamingWiki от 16.09. [Kotaku](https://kotaku.com/team-behind-popular-ocarina-of-time-pc-port-admit-to-using-ai-for-years-and-now-fans-are-freaking-out-about-vibecoded-slop-2000735358)

### The First Descendant 1.4.3 (вчера): античит сняли, а торговлю лучшим оружием открыли

![The First Descendant 1.4.3](https://www.keengamer.com/wp-content/uploads/2026/09/The-First-Descendant-Update-1.4.3-Cover.jpg)

Обновление 1.4.3 убрало из игры Easy Anti-Cheat и в том же патче сделало Transcendent-оружие торгуемым.

**Вывод.** Когда клиентская защита меняется, а ликвидный рынок лучших предметов открывается одновременно, вся проверка сделок и источника предмета обязана лежать на сервере — дюп и боты бьют по экономике быстрее, чем по матчам.

**Детали.** Nexon объясняет снятие Easy Anti-Cheat «изменением системы безопасности» и говорит о другом защитном решении. У торговли есть тормоза: сутки защиты на свежевыбитом предмете, минимальная цена по тирам качества (100/200/400/600 Caliber), потолок сделки 25 000 Caliber, комиссия 10% с продавца в Lounge Storage, миллион золота при сделке один на один, купленное привязывается и требует платного Trade Permit для перепродажи, вход по 15-му рангу мастерства. По API Steam на 18.09 — «смешанные», 64 446 положительных из 112 390. [По пересказу KeenGamer](https://www.keengamer.com/articles/guides/the-first-descendant-update-1-4-3-ultimate-hailey-and-all-changes/)

- **Unity 6.6 и Android SDK 37 (16.09): автоустановка кладёт платформу не туда** — на 6000.6.0f1 встроенный установщик создаёт каталоги `android-37.0` и `android-37.0-2`, после чего Gradle падает с «Observed package id 'platforms;android-37.0' in inconsistent location» и «Failed to find target with hash string 'android-37'». Обход из треда — снести обе папки и поставить платформу вручную через `sdkmanager`. [Unity Discussions](https://discussions.unity.com/t/unity-6-6-android-sdk-37-installed-in-inconsistent-location-causing-gradle-build-failure/1736692)
- **.NET 11 (18.09): массив указателей в P/Invoke приезжает битым** — issue #134174: при передаче `byte*[]` через `DllImport` нативная сторона получает верные младшие 32 бита и мусор в старших; по словам автора, на .NET 10 и на preview.1-4 всё работает, ломается с preview.5. Подозрение падает на перенос маршалинга массивов в управляемый код. Запись открыта, ответа команды нет. [dotnet/runtime](https://github.com/dotnet/runtime/issues/134174)
- **Воксели в Unity WebGL (16.09): свой импортёр .vox вместо готового пакета** — Кирилл Князев разбирает парсинг формата MagicaVoxel под Unity 6: чанки SIZE/XYZI/RGBA, палитра 256 цветов по 1024 байта, обработка по 4096 вокселей за итерацию корутины через `yield return null`, чтобы не вешать главный поток, мост в браузер через `[DllImport("__Internal")]` и `SendMessage`. [Habr](https://habr.com/ru/articles/1083022/)
- **NVIDIA (16.09): агент переписал 40 GPU-ядер с Python на Rust** — мульти-агентный конвейер перенёс все 24 публичных оператора TileGym из cuTile Python в cuTile Rust со средней производительностью 99,5% от исходной. Интересна не модель, а обвязка: каждая стадия заканчивается машинно-проверяемым вердиктом — скрипты-валидаторы и диффы Tile IR решают, пускать ли конверсию дальше. [NVIDIA Developer](https://developer.nvidia.com/blog/translating-cuda-tile-operations-from-python-to-rust-using-agentic-ai/)
- **Marvel's Wolverine (17.09): за границей уровня машины едут только в поле зрения** — ютубер Turned перелез через здание и вышел в незапечатанную часть карты: недорисованный лес, проваливающийся пол, доступ к поздним секциям без боевых триггеров. Самое наглядное — трафик, который вне зоны видимости въезжает в стены и исчезает. [Kotaku](https://kotaku.com/marvels-wolverine-open-world-level-bug-glitch-explore-2000735344)

## На горизонте

Дел, которые ещё не закрыты, хватает. Бета 6.7 только открылась, и первые жалобы на URP с пост-обработкой уже поступили — ждём, во что это оформится в трекере. Unity выпустила плагин для ещё одного агента — без MCP-сервера, одними навыками, и стоит посмотреть, чем такая поставка отличается на практике. UI Toolkit в 6.7 обещает 10-40% на генерации текста — цифру хочется увидеть чужими руками. У OpenVDB появился SIMD-фреймворк с обещанным ускорением вдвое-вчетверо на переносе точек — это про бейк волюметрики в игровом пайплайне. И отдельная линия: Vulkan-бэкенд вместо OpenGL в живой двадцатилетней MMO — там вот-вот должны пойти замеры.

Проверяйте, откуда взялся код, пока это ещё можно выяснить.
