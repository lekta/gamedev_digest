# GameDev Digest — 2026-11-05

День, считайте, удачный: Cloud Code в Unity 6.7 вышел из экспериментов и теперь сам держит состояние между вызовами, а раньше его приходилось складывать руками. Профсоюз Arkane Lyon назвал причину сорванных сроков Marvel's Blade — девятнадцать месяцев заморозки найма, и это уже сказано вслух, а не угадывается. Лончер NIKKE больше месяца раздавал игрокам агент удалённого доступа с официального CDN издателя, зато теперь понятно, что проверять у себя. А в JIT нашли switch по строкам, который под AOT компилировался минутами, и фикс принесли в тот же день.

### Unity (вчера): Cloud Code 3.0 вышел из экспериментов официальным пакетом 6.7
Новость: серверные модули получили состояние между вызовами и локальную отладку с брейкпоинтами.
**Вывод.** Апгрейд ломающий: классы в `Unity.Services.CloudCode.Apis` стали internal, обращаться к сервисам теперь надо через `IGameApiClient` и `IAdminApiClient`.
**Детали.** В анонсе сказано: «starting in Unity 6.7, Cloud Code 3.0 has been released as an official package!», при этом «The package needs Unity 6000.7 or newer.». Модули целятся в .NET 10, на нём же работают локальный сервер и генератор биндингов, так что понадобится .NET 10 SDK. Атрибут `[StateScope]` хранит публичные поля и свойства модуля между вызовами: `Scope.Player` даёт каждому игроку свой экземпляр, `Scope.MultiplayerSession` — один общий на сессию; памяти на воркер стало 512 МБ вместо 256. [Unity Discussions](https://discussions.unity.com/t/1741157)

### Arkane Lyon (вчера): профсоюз говорит, что Microsoft сама сорвала игру, которую финансировала
Новость: STJV заявил, что студию закрывают по решению Microsoft, а не из-за экономики проекта.
**Вывод.** Девятнадцать месяцев заморозки найма — это не экономия, а растянутые сроки, которые потом становятся аргументом за закрытие команды.
**Детали.** Под угрозой 217 штатных сотрудников плюс контракторы и фрилансеры; дедлайн по продаже студии Microsoft сдвинула с 13 ноября на 13 декабря. Профсоюз формулирует жёстко: «Arkane is profitable. Just not profitable enough for Microsoft», а закрытие, по его оценке, «would probably be more expensive than finishing the game». Требования — выходное пособие 200 000 евро на человека и два года оплаченного Microsoft трудоустройства. [GamesIndustry.biz](https://www.gamesindustry.biz/arkane-union-accuses-microsoft-of-sabotaging-marvels-blade-with-19-month-hiring-freeze)

### NIKKE (вчера): в PC-лончер через официальный CDN подменили четыре скрипта
Новость: игрокам больше месяца раздавали агент удалённого доступа прямо из обновления клиента.
**Вывод.** Скрипты, которые лончер тянет с вашего CDN на старте, — это исполняемый код в проде, и контроль целостности им нужен не меньше, чем самой сборке.
**Детали.** Level Infinite подтвердила: «We have identified an issue indicating that the PC Launcher's script files may have been tampered with by a third party», и сообщила, что «client fixes and an update were implemented on November 4 at approximately 02:30 (UTC+9)». По разбору исследователя MotherSphere подменены четыре JS-файла на официальном CDN издателя: нагрузка `insight.bundle` ставила агент удалённого доступа K2F и библиотеку `platform_experience_helper.dll`, которая продолжала работать после закрытия лончера, а целями были пароли аккаунта, данные браузеров и кошельки расширений MetaMask, Phantom и Coinbase Wallet. Файлы правили с 27 сентября, три заменили на чистые только 3 ноября. [BleepingComputer](https://www.bleepingcomputer.com/news/security/nikke-pc-game-launcher-hacked-to-spread-remote-access-data-stealing-malware/)

- **Rider (сегодня): 2026.3 дошёл до релиз-кандидата с поддержкой C# 15** — сборка 263.7307.196 понимает юнионы, закрытые иерархии классов и помеченные `break`/`continue`, плюс превью модели `safe`/`unsafe`. Для Godot добавили отладку C# и GDScript с обходом дерева сцены, для Unreal — отладчик на LLDB 21 по желанию, по умолчанию остаётся LLDB 9. [JetBrains](https://data.services.jetbrains.com/products/releases?code=RD&latest=false&type=rc)
- **.NET (вчера): большой switch по строкам ломает время AOT-компиляции** — filipnavara завёл issue #136968: время компиляции растёт примерно в 9–10 раз при каждом удвоении числа кейсов, потому что вставка в список предшественников блока каждый раз перебирает его с головы. Фикс AndyAyersMS #136976 роняет медианное время JIT на метод с примерно 178 секунд до 0,85 при четырёх тысячах кейсов; на репро образы R2R до и после совпали побайтово, но по библиотекам у 69 методов из 41 455 размер кода всё же сдвинулся. [GitHub](https://github.com/dotnet/runtime/issues/136968)
- **Roslyn (сегодня): `is 'a' or 'b' or …` компилируется в бинарный поиск и теряет оптимизацию JIT** — цепочка `||` с `==` сворачивается в один `bt` с константной маской, а равнозначный паттерн нет: 89 байт кода против 52. Воспроизводится на .NET 9, 10 и 11 RC3, у `switch` то же самое; автор предлагает отдавать линейную цепочку сравнений, когда все константы влезают в 64-битное окно. [GitHub](https://github.com/dotnet/roslyn/issues/86322)
- **ArcheAge Chronicles (вчера): ранний доступ встал на багах, запирающих прогресс** — игроки не могли выйти из обучения, боссы не спавнились, а распад пати внутри данжа блокировал прохождение; воркэраунд — не расходиться до выхода из инстанса. XLGames обещает расписание фиксов, краши — следующим патчем. На 5 ноября страница в Steam показывает «Mixed» и 67% положительных из 990 отзывов. [Massively OP](https://massivelyop.com/2026/11/04/archeage-chronicles-early-access-release-sees-progression-halting-bugs-and-mixed-steam-reviews/)
- **Россия (сегодня): серые перепродавцы доступа к зарубежным ИИ вышли на 100–150 млн рублей в месяц** — по данным «Ведомостей», которые приводит 3DNews, таких фирм стало 50, и «Цены у серых поставщиков могут быть до 70 % ниже официальных тарифов API».
