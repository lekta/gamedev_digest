# GameDev Digest — 2026-08-13

Ночь на связи, разбираю входящие. Первым дозвонился Microsoft: вышло седьмое превью .NET 11, и асинхронность там теперь родная для рантайма, а не надстройка компилятора. Следом — звонок недельной давности: Unity в ветке 6.7 открыла публичный доступ к кастомизации главной панели редактора, свои кнопки вешаются без единой строки кода. Под утро считали, во что ИИ переформатирует команды, отпускали два корейских MMORPG на волю и радовались двум миллионам проданных мячей. Крупного релиза движка в эфир сегодня не прорвалось — веду тем, что дозвонилось.

### .NET 11 Preview 7 (11.08): асинхронность становится частью рантайма
Microsoft выпустила седьмое превью .NET 11 — предпоследнюю остановку перед ноябрьским релизом.

**Вывод.** Главное для игрового кода — «родной для рантайма» async с ярусной компиляцией и оптимизацией хвостового await: меньше накладных на конечный автомат, который раньше разворачивал компилятор. Когда Unity доедет до CoreCLR-плеера, этот путь напрямую влияет на аллокации и старт асинхронщины в игровом цикле.

**Детали.** В C# завезли помеченные break/continue, сопоставление с образцом по union-типам и проверку полноты для параметров с closed-ограничением. Режим NativeAOT в dotnet CLI и сервер MSBuild включены по умолчанию, dotnet test получил --timeout и --maximum-failed-tests. В библиотеках — Complex<T>, десятичный тип по IEEE 754 и полиморфизм по закрытым иерархиям в System.Text.Json. Общий релиз .NET 11 — ноябрь 2026. [.NET Blog](https://devblogs.microsoft.com/dotnet/dotnet-11-preview-7/)

### Главная панель Unity 6.7 (07.08): свои кнопки на тулбаре без кода
Unity открыла публичный API кастомизации главной панели редактора в ветке 6.7.

**Вывод.** Для редакторного тулинга это способ повесить нужные действия на постоянно видимую панель — не пряча их по подменю и не заводя отдельное окно. Любимые пункты меню добавляются на панель мышью через QuickSearch, без единой строки кода.

**Детали.** Класс MainToolbarCustomElement стал public API — свой элемент можно наследовать от MainToolbarButton и дёргать EditorApplication.ExecuteMenuItem() со своей иконкой. Группы элементов и переключатели теперь визуально отличимы от кнопок, чего раньше не хватало. Анонс — Томас Лопес, 07.08; фича катится в альфе 6.7. [Unity Discussions](https://discussions.unity.com/t/customizable-main-toolbar-unity-6-7-improvements/1733331)

Из прошлого: в августе 2012-го вместе с C# 5.0 и .NET Framework 4.5 появились async/await. Компилятор сам разворачивал асинхронный метод в конечный автомат — состояние сопрограммы жило в сгенерированной структуре, и за удобство линейного кода платили этой обёрткой. Четырнадцать лет спустя .NET 11 убирает слой, встраивая асинхронность в сам рантайм. Идея прежняя — писать прямой код поверх ожиданий, — только цена под капотом наконец падает.
