# GameDev Digest — 23 сентября 2026

Тридцать лет я допрашивал сборки, и сегодня три признания. Unity назвала content directories заменой AssetBundles и показала ссылку `Loadable<T>`, которая грузит артефакт сама. В Unity CLI завелась команда `unity recompile` — проверить компиляцию скриптов без полной сборки, с отдельным кодом возврата для конвейера. А Конрад Кокоса собрал на C# симулятор мушиного мозга и нашёл, куда утекали пятнадцать микросекунд на шаг.

### Content directories (22.09): Unity официально назвала их заменой AssetBundles

![Content directories](https://cdn.sanity.io/images/fuvbjjlp/production/f20282efda5bd8e4704df03ca76d8e89135f06b2-1600x750.png)

Unity объявила content directories заменой AssetBundles и показала новый тип ссылки `Loadable<T>`.

**Вывод.** Раскладку бандлов проектировать больше не нужно: рантайм сам находит, грузит и выгружает отдельные меши и текстуры, а проект на Addressables переезжает без правок кода.

**Детали.** Формулировка из блога — «более производительная и более гранулярная замена AssetBundles». Работает в Unity 6.6 для контента, который едет вместе с плеером; удалённая доставка обещана в поколении Unity 7. Пример миграции без единой строки кода — Slime Rancher 2. Автор поста — старший инженерный менеджер Джордж Инг. [Unity](https://unity.com/blog/content-directories-beyond-the-assetbundle)

### Unity CLI 1.0.0-beta.11 (22.09): компиляция проверяется без полной сборки

Вышла бета Unity CLI с командой `unity recompile`, которая проверяет сборку скриптов в запущенном редакторе.

**Вывод.** Для проверки правок на конвейере больше не нужен полный билд: команда возвращает 0 при успехе, 6 при ошибках компиляции и 7, если редактор не отвечает.

**Детали.** Ошибки печатаются с именем файла и номером строки. В том же выпуске — экспорт и импорт `.unitypackage` из терминала, `unity docs` под версию проекта, `unity run --log-file`, чтение ресурсов Build Automation. Починили заголовки сжатия для WebGL-сборок и работу через прокси; обновление через `unity self-update`. Анонс christophera_unity. [Unity Discussions](https://discussions.unity.com/t/unity-cli-1-0-0-beta-11-is-rolling-out/1737353)

### dotFly (22.09): нервная система дрозофилы считается на чистом C#

Конрад Кокоса выложил движок, который гоняет коннектом мухи на .NET быстрее реального времени.

**Вывод.** Атрибут `[MethodImpl(MethodImplOptions.AggressiveOptimization)]` срезал шаг с 21 до 6 микросекунд — на горячем цикле разогрев многоуровневой компиляции стоит дороже, чем принято думать.

**Детали.** 166 700 нейронов и около 25 млн синапсов, `Vector256<float>` по 8 нейронов за инструкцию, структура массивов в неуправляемой памяти с выравниванием на 64 байта — всё состояние около 2 МБ. Ноль выделений памяти на горячем пути, коннектом читается как отображённый в память файл в формате CSR, 62 000 шагов в секунду на восьми потоках. Лицензия GPLv3. [kokosa.dev](https://kokosa.dev/blog/2026/dotfly/)

- **OZARK (22.09): шесть лет на Unity 2022 LTS и Built-in RP** — студия Alter Boy в интервью 80.lv объясняет консервативный выбор знанием пайплайна: из стороннего только NGSS для теней и решение для обратной кинематики, геймплейная архитектура, ИИ, поведение камеры и внутренние инструменты написаны сами. Фиксированную 2.5D-перспективу называют главным техническим бременем — под неё пришлось делать своё прицеливание и захват цели, а поведение врагов проектировать с оглядкой на край кадра. [80.lv](https://80.lv/articles/ozark-creating-a-dark-story-driven-2-5d-action-horror-game)
- **DLSS 5 (22.09): нейронный проход поверх готового кадра** — NVIDIA добавила 3D-Guided Neural Rendering: сеть получает отрисованный движком кадр вместе с геометрией, текстурами и буферами освещения, работает по строгой схеме «кадр на входе — кадр на выходе» на векторах движения движка, до 4K и только на RTX 50. Первой едет NBA 2K27. Заодно вышел RTX Kit 2026.3, где у Mega Geometry 2.0 появился стриминг кластеров с непрерывным уровнем детализации. [NVIDIA](https://developer.nvidia.com/blog/whats-new-for-game-developers-dlss-5-with-3d-guided-neural-rendering-nvidia-ace-updates-and-new-rtx-kit-capabilities/)
- **Metal Display Link на macOS (21.09): переключение окна вешает игру** — при включённом `metalUseMetalDisplayLink` выход из игры и возврат обратно намертво подвешивают приложение; автор треда eMkaQQ воспроизводит на 6000.5.5. Обход — переменная окружения `UNITY_USE_METAL_DISPLAY_LINK=0`, но тогда теряются и остальные выигрыши фичи; ответа Unity в треде пока нет. [Unity Discussions](https://discussions.unity.com/t/tabbing-out-freezes-the-game-on-macos-with-metal-display-link-enabled/1737149)
- **Дамп памяти из своего процесса (22.09)** — Аарон Пауэлл в блоге .NET показывает, как приложение снимает дамп само: фоновый `ThreadPoolWatcher` периодически кидает задачу в пул и меряет задержку, а по превышению порога зовёт `MiniDumpWriteDump` из `dbghelp.dll` на Windows или утилиту `createdump` на Linux. В примере дамп весит около 125 МБ на Windows и около 800 МБ на Linux; автор отдельно предупреждает, что внутри лежат строки подключения и токены. [.NET Blog](https://devblogs.microsoft.com/dotnet/creating-a-memory-dump-in-csharp/)
- **BusEngine (23.09): запуск ядра с 500 мс до 30-50 мс** — BuslikDrev на DTF разобрал старт своего движка на C# по замерам: вынос вызовов Windows API для консоли и логов в фоновый поток дал 50-80 мс, отказ от `dynamic` в пользу своего класса настроек с вложенными словарями — около 200 мс, замена Newtonsoft.Json собственным разбором без выделений памяти добила до тридцати. Мерилось на слабом ноутбуке с жёстким диском; общий запуск ускорился примерно втрое. [DTF](https://dtf.ru/gamedev/5314130-optimizatsiya-dvizhka-busengine-na-cshar-i-okhrana-kotov-na-dache)

## На горизонте

Несколько дел пока открыты. Unity назвала срок выхода 6.7 из беты — конец ноября или начало декабря, и к этому сроку обещан большой заход по UI Toolkit. Команда Unity Version Control набирает людей в ранний доступ к встроенному разбору правок прямо в системе контроля версий. Висяк недели — фатальный сбой доступа к памяти в Roslyn при первой компиляции совершенно пустого проекта на 6000.3.24f1 и 6000.6.0f1, на который Unity пока не ответила. И сбоку подъезжает генерация трёхмерных моделей сразу квадами: Tripo обещает четырёхугольную сетку с внятными рёбрами, то есть без промежуточной переразбивки перед развёрткой и скиннингом.

Проверяйте коды возврата, а не бодрые сообщения в логе. Свободны.
